Before deploying

  • Rotate the .env.bak keys first, GVerify before the others. Nothing else in this log matters much while a working key sits in git history.
  • The backend's GOOGLE_CLIENT_ID must equal the frontend's NEXT_PUBLIC_GOOGLE_CLIENT_ID in every environment, or Google sign-in returns 500 (missing) or 401 (different).
  • Reset links emailed before the reset fix deployed no longer work; users request a new one.
  • This round changed Edward's app/utils/ (r2.py, email.py, jwt.py) and the shared app/auth/. It's already on main, so it needs his review after the fact.
  • Uncomment the vbsec lines in the backend .gitignore before anyone runs git add ..
